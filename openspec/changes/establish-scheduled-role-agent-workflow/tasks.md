## Lead pre-handoff readiness (not an Executor implementation task)

Before Lead routes a newly authored or materially revised OpenSpec change to `Reviewer / review-openspec`, Lead MUST obtain current strict OpenSpec validation and perform the bidirectional traceability/readiness check required by the `propose-change` contract. A successful repository `OpenSpec Validate` GitHub Actions run for the exact current revision is acceptable durable strict-validation evidence; Lead MUST NOT require an additional local CLI run solely because the evidence came from CI. If exact-revision CI evidence is unavailable, Lead may obtain the equivalent validation by running the repository-pinned OpenSpec CLI command directly.
