## Decision 1 — CONSOLIDATE shared runtime owner

Put one concentrated Invocation Exit/continuation section in AGENTS.md adjacent to its existing one-wake boundary, referring to existing exception finalization, Human authority, stale/precondition and CarrierRequired contracts instead of copying their logic. Before a voluntary return, establish an already-governed legal Exit from current evidence: complete Action with observed formal result/successor or terminal, actual external wait with no further bounded lawful opportunity, existing handoff/authority or stale/unsafe disposition, or true hard execution boundary. Preserve real interruption and later durable reconstruction; do not require fabricated evidence for an uncatchable termination.

A Worker Result is semantic input, Application performs repository-owned effects, and Action completion requires the appropriate verified postconditions and formal result; no intermediate API or run success substitutes. Positive Exit proof is an internal return precondition, not a new field, label, event, classifier, or persisted state. If no legal boundary is established and actionable work remains, continue the current Action. On required nonterminal resources, keep observing the same exact resource with bounded opportunity and fresh authority; terminal success or failure is consumed and remaining lawful work proceeds. No fixed number of reads, busy waiting, self-imposed response deadline or newly invented timer. Respect the hard CarrierRequired boundary, exact-revision gates, stale and reserved Human authority; do not run any successor in the same wake. Distinguish a forced external interruption from voluntary yield.

## Alternatives and trade-offs

REMOVE discretionary stopping shortcuts; REUSE existing exit/authority/effect owners; CONSOLIDATE in existing shared owner. Extra wait registry, deterministic runtime classifier, timer or enforced scheduler-side continuation would introduce unnecessary authority and/or violate the Human-approved no-delta scope. Prompt/Skill duplication would drift. No design promises a measurable remaining host budget if it is not exposed, guarantees an uncatchable interruption can be finalized, or requires global serialization. Real observed inability may delimit a bounded invocation; voluntary progress reporting or count of pending observations is not such evidence.
